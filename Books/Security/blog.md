# Security

## Books
- **Web Application Security** (Andrew Hoffman, 2nd ed. 2024) — OWASP Top 10, security fundamentals for web developers.
- **Threat Modeling: Designing for Security** (Adam Shostack, 2014) — STRIDE methodology, threat modeling as a design activity.
- **The Web Application Hacker's Handbook** (Stuttard, Pinto, 2nd ed.) — How attackers think. Penetration testing methodologies.
- **Security Engineering** (Ross Anderson, 3rd ed. 2020) — Comprehensive security engineering textbook. Protocols, access control, crypto, physical security.
- **AWS Security** (Dylan Shields, 2022) — Cloud-specific security architecture.

## Foundational Papers
- **The Protection of Information in Computer Systems** (Saltzer, Schroeder, 1975) — Design principles: least privilege, fail-safe defaults, economy of mechanism, complete mediation, open design, separation of privilege, least common mechanism, psychological acceptability.
- **Reflections on Trusting Trust** (Ken Thompson, 1984) — Supply chain attacks. Turing Award lecture.
- **Why Cryptosystems Fail** (Ross Anderson, 1994) — Security failures are rarely cryptographic; they're systemic.

## Certifications
- **CISSP** — Comprehensive security knowledge
- **AWS Certified Security – Specialty** — Cloud security
- **Certified Kubernetes Security Specialist (CKS)** — Container and K8s security
- **OSCP (Offensive Security Certified Professional)** — Hands-on penetration testing
