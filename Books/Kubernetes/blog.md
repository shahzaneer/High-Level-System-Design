# Kubernetes

## Books
- **Kubernetes in Action** (Marko Luksa, 2nd ed. 2022) — Comprehensive Kubernetes guide. Pods, deployments, services, storage, security, operators.
- **Production Kubernetes** (Josh Rosso et al., 2021) — Building production-grade K8s. Cluster architecture, networking, storage, security, observability, CI/CD.
- **The Kubernetes Book** (Nigel Poulton) — Accessible introduction. Rapid-start approach.
- **Cloud Native DevOps with Kubernetes** (John Arundel, Justin Domingus, 2nd ed.) — DevOps practices on Kubernetes.
- **Managing Kubernetes** (Brendan Burns, Craig Tracey, 2018) — Operating Kubernetes at scale. SRE perspective.

## Foundational Papers
- **Large-scale cluster management at Google with Borg** (Verma et al., 2015) — The predecessor to Kubernetes. Borg's architecture, scheduling, failure recovery.
- **Borg, Omega, and Kubernetes** (Burns et al., 2016) — Lessons learned from three generations of container management.
- **Autopilot: workload autoscaling at Google** (Rzadca et al., 2020) — Vertical and horizontal autoscaling at Google scale.

## Key Resources
- **Kubernetes Documentation** (kubernetes.io/docs) — Official, comprehensive. Start with Concepts section.
- **CNCF Landscape** (landscape.cncf.io) — The cloud-native ecosystem visualized.
- **Kubernetes Failure Stories** (k8s.af) — Real production incidents and lessons.
- **Learn Kubernetes Basics** (kubernetes.io/docs/tutorials) — Interactive tutorials.
