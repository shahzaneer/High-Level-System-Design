# Cloud Architecture

## Books
- **Cloud Native Transformation** (Pini Reznik et al., 2019) — Patterns for organizational change toward cloud-native.
- **Infrastructure as Code** (Kief Morris, 2nd ed. 2020) — Terraform, CloudFormation, patterns, testing IaC.
- **Terraform: Up & Running** (Yevgeniy Brikman, 3rd ed. 2022) — Practical Terraform for AWS.
- **The Cloud FinOps Book** (J.R. Storment, Mike Fuller, 2nd ed. 2023) — Cloud financial operations and cost optimization.
- **Cloud Strategy** (Gregor Hohpe, 2020) — Enterprise cloud adoption, platform thinking, organizational patterns.
- **The Site Reliability Workbook** (Beyer et al., 2018) — Practical SRE implementation. SLIs, SLOs, error budgets, on-call, incident response.

## Provider Documentation (Must-Reads)
- **AWS Well-Architected Framework** — Six pillars: operational excellence, security, reliability, performance efficiency, cost optimization, sustainability.
- **Google Cloud Architecture Framework** — Same concepts, GCP-specific guidance.
- **Microsoft Azure Well-Architected Framework** — Five pillars: cost optimization, operational excellence, performance efficiency, reliability, security.
- **AWS Builders' Library** — Deep dives on distributed systems patterns by Amazon engineers.

## Additional Papers
- **Above the Clouds: A Berkeley View of Cloud Computing** (Armbrust et al., 2009) — Foundational cloud computing paper.
- **A View of Cloud Computing** (Armbrust et al., 2010) — Updated view; obstacles and opportunities.
- **Serverless Computing: One Step Forward, Two Steps Back** (Hellerstein et al., 2019) — Critique and analysis of serverless architecture.

## Key Certifications
- **AWS Solutions Architect Professional** — The gold standard cloud architecture cert
- **Google Professional Cloud Architect** — GCP equivalent
- **Microsoft Azure Solutions Architect Expert** — Azure equivalent
- **HashiCorp Terraform Associate** — IaC certification
- **CKAD/CKA/CKS** — Kubernetes application developer, administrator, security
